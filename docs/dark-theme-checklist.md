# 全站深色与荧光绿主题

## 主题入口

- `resources/css/theme.css` 集中定义 Tailwind 4 语义色彩与共享 `ui-page`、`ui-card`、`ui-control`、`ui-button`、`ui-button-primary`、`ui-table` 样式，经 `app.css` 加载。
- 主色：背景 `#151A18`、卡片 `#222A26`、次级表面 `#2C3530`、边框 `#3D4841`、正文 `#F3F6F1`、辅助文字 `#B4BFB6`、强调色 `#C5F564`。成功、警告、危险和信息有独立深底及浅色文字。
- 15 个 Vue 页面组件、学生列表的毕业生模式、权限不足及 CAS 错误页统一使用主题。人员权限、辅导员的局部 CSS 已改用共享变量。
- PC 统一页面 24px 留白、卡片 20px 内距；标题、控件、按钮、表格和弹窗使用共享规则。学生表保持原表头顺序，使用固定列宽及长文本换行。
- 未新增字段、操作入口、主题切换或组件库。后端接口、参数、校验、权限和业务处理保持原样。

## 移动端适配要点

- 所有手机媒体查询新增内容集中在 `resources/css/mobile.css`，继续使用最大 767px 断点。导航抽屉原组件的手机样式已迁入该文件。
- 复用已有单列、操作区换行和局部横向滚动规则；手机卡片内距 16px，输入控件及操作按钮触摸高度至少 44px。
- 弹窗操作区与导航抽屉采用深色背景，继续使用 Visual Viewport 高度及底部安全区。
- 导航容器增加 `min-width: 0`，解决 768px 平板宽度下的整页溢出。
- 独立 Blade 提示页同样覆盖手机内距和按钮触摸高度。

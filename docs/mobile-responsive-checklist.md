# 手机端适配与自测

技术栈：Laravel 12、Vue 3、Tailwind CSS 4、Vite。

## 改动与回滚

- `resources/css/mobile.css` 通过 `app.css` 引入，全部规则限定在最大 767px 和 `#app` 内。`mobile-stack`、`mobile-wrap`、`mobile-modal`、`mobile-calendar` 为纯布局钩子。
- 学生详情的 `MobileProfileNavigation` 包装原导航，手机端支持抽屉、遮罩关闭、Escape、焦点循环及关闭后焦点返回；桌面端保留侧栏。
- `mobileViewport.js` 通过 Visual Viewport 更新弹窗可视高度，不支持该 API 时使用窗口高度。表单操作区在滚动面板底部显示并预留安全区。
- 回滚时撤销本次前端改动并重新运行 `npm run build`。仅移除移动样式 import 可关闭大部分覆盖，但完整回滚还需恢复详情导航包装和移除 viewport 初始化。无需数据库操作。
- 后端接口、业务计算、原有提交处理和校验未调整。
